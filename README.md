# Vinyl Control

Sistema web para gerenciamento do estoque de uma loja de discos de vinil e colecionáveis.

## Sobre o projeto

O Vinyl Control foi desenvolvido para facilitar o controle de discos, vendas e reposições de estoque. A proposta é substituir os registros manuais por um sistema informatizado, ajudando a evitar erros, organizar o acervo e acompanhar a quantidade de produtos disponíveis.

## Funcionalidades

- **Login:** autenticação de usuários.
- **Cadastro de discos:** inclusão, consulta, edição e exclusão de discos.
- **Busca:** pesquisa de discos cadastrados.
- **Controle de estoque:** registro de entradas por reposição e saídas por venda.
- **Movimentações:** registro da data, da quantidade e do usuário responsável por cada operação.
- **Estoque mínimo:** alerta quando a quantidade de discos fica abaixo do limite definido.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- API para gerenciamento dos dados
- Banco de dados para armazenamento das informações

## Objetivo

O objetivo do projeto é tornar o gerenciamento da loja mais simples e eficiente, mantendo as informações dos discos organizadas e facilitando o acompanhamento das movimentações de estoque.

O sistema foi desenvolvido como parte do Simulado SAEP do curso Técnico em Desenvolvimento de Sistemas, envolvendo análise de requisitos, modelagem de banco de dados, desenvolvimento, testes e documentação.
